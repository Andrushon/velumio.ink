## Ограничение озвучки

Прямой `POST /audio/speech` управляемым AI-подключением не поддерживается; старый `/api/tts` не используется текущим интерфейсом. Запрос `/models` также не является рабочей проверкой доступности этого прокси.

Помощники продолжают использовать бесплатную озвучку устройства с профилями для всех 18 персонажей. Исправлено ложное совпадение `female` с `male`; Вуку подобрана манера книжного эльфа, а голосовой профиль детектива отделён от волка.

AI-озвучка через поддерживаемый аудиочат возможна, но её включение требует согласования расходов AI-кредитов. Не включать автоматически.
