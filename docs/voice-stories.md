# История голосом

В библиотеке доступна кнопка «Рассказать историю». Такой же переход есть в разделе загрузки рукописи.

1. Указать название и начать рассказ. Микрофон запрашивается до создания книги.
2. Читать свою историю или придумывать сюжет вслух. Распознаваемый текст появляется небольшими фрагментами; его можно исправлять прямо в редакторе.
3. Иллюстрации создаются по уже рассказанным событиям: первая примерно после 20 слов, следующие — после 70 новых слов. Для языков без пробелов также учитываются символы. Автоматические картинки можно отключить.
4. Поставить запись на паузу или продолжить. При ошибке распознавания фрагмент остаётся в очереди для повтора.
5. Завершить и сохранить. Сначала обрабатывается последний аудиофрагмент; для завершения требуется не менее 50 символов.
6. В библиотеке открыть «Редактировать / продолжить» у собственной истории: изменить текст, продолжить рассказ или отредактировать картинки.

## Сохранение и ограничения

- Текст автоматически сохраняется на сервере. На устройстве остаётся пользовательская копия несохранённых правок.
- Если другая вкладка изменила текст, приложение предлагает разрешить конфликт, а не молча перезаписывает новую версию.
- Изменение текста не удаляет прежние иллюстрации.
- Истории и картинки привязаны к автору; картинки не попадают в общую библиотеку сцен.
- Действуют существующие ограничения сеансов и генерации иллюстраций. Редактирование картинки требует существующих платных кредитов и явного подтверждения.
- Исчерпание лимита картинок не должно мешать диктовке и сохранению текста.
- Аудио используется для распознавания и повторной отправки при ошибке, но этот экран не сохраняет полный аудиофайл для скачивания. Перед обновлением страницы нужно дождаться обработки фрагментов.
- Голоса помощников не меняются: остаётся выбранная пользователем бесплатная озвучка устройства.
