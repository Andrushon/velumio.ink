# Будущие возможности Velumio

## Видео по прочитанной истории — за дополнительную плату

**Запрос:** применять уже сгенерированные иллюстрации для создания видео по прочитанной истории за дополнительную плату.

**Статус:** будущая возможность; оплату и новую генерацию сейчас не включать.

### Предлагаемый порядок реализации

1. Уточнить формат: существующий MP4-фильм из иллюстраций или отдельная AI-анимация этих иллюстраций. Расширять существующий механизм фильмов, а не дублировать его.
2. Использовать принадлежащие пользователю иллюстрации выбранного сеанса в порядке событий. Для авторских историй сохранять приватность и исключительность.
3. Сценарий ограничивать подтверждённо прочитанным текстом, без продолжения из знаний модели и без спойлеров.
4. До запуска показывать родителю состав видео, ожидаемую длительность и отдельную цену. Не расходовать подарочные иллюстрации и не менять уже действующие права подписок.
5. Подключить разовую оплату через существующий Stripe. Предусмотреть защиту от повторного списания и возврат при окончательной ошибке создания.
6. Добавить очередь, прогресс, сохранение результата в App Storage и скачивание готового видео.

Стоимость и выбор движка определить после замеров себестоимости. AI-анимация и озвучка — отдельные решения, не обязательные части первого варианта.

## Голоса помощников

Сейчас оставить бесплатные голоса устройства. Платные голоса помощникам сделать, когда проект начнёт приносить прибыль.
